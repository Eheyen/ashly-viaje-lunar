# Ashly · Un viaje a través de tus recuerdos

Página estática personalizada con seis escenas, fotografías, música continua y pantalla de carga. Optimizada para celular y escritorio.

## Abrir
Abre `index.html` en un navegador o sirve esta carpeta con cualquier servidor web estático. Toca **Comenzar el viaje** para activar la música. El control superior permite pausar y reanudar; el reproductor completo está en la escena de música.

## Editar
El diseño y las escenas están en `index.html`. El objeto `personalizacion` contiene las fotografías y la dedicatoria. La canción está en `all-i-can-say.mp3`.

## Créditos
Consulta `creditos.html`. Dos retratos fueron mejorados mediante IA a partir de fotogramas proporcionados por el usuario. Las fotografías y la canción conservan sus respectivos derechos; este repositorio no concede una licencia sobre esos archivos.
